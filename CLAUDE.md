# milestone-escrow

Entry for the Arbitrum Open House São Paulo Online Buildathon (HackQuest, submission from 2027-02-08, deadline 2027-03-01).

- Contracts: `src/` (Foundry). Tests: `forge test` (24 tests, 2 fuzz). Setup: `forge install foundry-rs/forge-std --no-git`.
- Frontend: single `index.html` (ethers 6), served by GitHub Pages from `main` root.
- Deployed on Arbitrum Sepolia; addresses in README. Deploy with `deploy.sh` (key from the local secret vault, never committed).
- Contest status, decisions and logs live in the private contest-pm repo: `contests/0301-arbitrum-sao-paulo/status.md`. This repo is the public deliverable.
